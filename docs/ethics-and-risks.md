# Ethics, risks and mitigations
| Risk | Consequence | Mitigation / release gate |
|---|---|---|
| Exposure confused with displacement | Workers misled | Clear definitions beside outputs; no job-loss probabilities |
| HVI read as human worth | Stigma and harmful ranking | Explain measured dependencies; prohibit ranking individuals |
| Unvalidated LLM labels | Circular evaluation | Separate annotations; independent held-out review and baseline |
| Source/crosswalk mismatch | Incorrect wages or double-counted employment | Versioned official mappings and coverage audit |
| Small-area noise / suppression | False precision and unstable county rankings | Retain ACS MOEs, null flags and sensitivity; suppress unsupported comparisons |
| Aggregates treated as personal skills | Unrealistic transitions | Label occupation proxies; allow explicit worker confirmation |
| Licensing and inaccessible training | Harmful career advice | Feasibility gates; unknown costs/time remain unknown |
| Cultural inference from job titles | Stereotyping | Consented interviews and domain review; no inferred cultural scores |
| Data terms unclear | Unauthorized redistribution | Record terms; exclude restricted/unclear files from public repository |
| Task data stale as AI changes | Overstated capability | Capability date and scheduled methodological re-evaluation |
| Personal interview disclosure | Privacy and ownership harm | Consent, minimization, participant review and deletion; separate storage |
| Scope overload | No usable MVP | Gate map, knowledge pilot and advanced graph work behind core demo |

Never recommend termination, hiring rejection or wage reduction. Protected attributes are not individual recommendation inputs. Aggregate demographic research requires a documented purpose and review.

Knowledge preservation needs informed consent, permitted reuse, participant ownership choices, access controls, correction/deletion procedures and a distinction between testimony and verified facts. Public occupational datasets do not supply a ready-made collection of personal cultural or tacit knowledge.

No paid datasets, paid APIs, cloud infrastructure or third-party messaging are authorized by the Phase 0 plan. Ordinary implementation and repository updates remain in scope.
