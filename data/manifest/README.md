# Acquisition manifests
Five immutable core acquisition manifests are committed. The core snapshot lock selects exact hashes and records observed workbook vintages. Raw bytes are downloaded or manually registered into data/raw; they are excluded from Git.

Required fields and review rules are in ../README.md. Never store credential-bearing request URLs. Structural and workbook validation results are in docs/reports/core-data.json and docs/data-cards/core-sources.md. The initial manifest labels are preserved; current observed releases and terms review are documented separately.
